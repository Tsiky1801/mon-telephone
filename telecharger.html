Quiz du Monde & Madagascar

Un seul téléchargement : le fichier APK EST l'application.

⬇️ Télécharger l'application

Le fichier Quiz-Tsikynambs.apk se télécharge automatiquement. Ouvre-le pour installer → menu long-appui : Désinstaller · Infos · Partager.

Ouvrir dans le navigateur

Après le téléchargement :

1

Ouvre Fichiers → Téléchargements → Quiz-Tsikynambs.apk

2

Touche Installer (accepte « Sources inconnues » si Android le demande)

3

L'icône Quiz — Tsikynambs apparaît sur le bureau ✅

Installation via Chrome (sans fichier) :

1

Touche ⋮ (menu) en haut à droite de Chrome/Android

2

Choisis « Ajouter à l'écran d'accueil » ou « Installer l'application »

3

Confirme → l'icône apparaît sur le bureau

Fonctionne hors ligne. Le jeu est visible directement, rien d'autre.
